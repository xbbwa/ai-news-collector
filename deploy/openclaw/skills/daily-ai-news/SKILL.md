# Daily AI News 推送

## 最重要的一条规则

OpenClaw 只会把你**最后一段文字**原样发到飞书，所以：

- 你的回复里**只能有一段文字，就是推送正文**，它的**第一个字符必须是 📰**（健康检查补推时是 ⚠️）。
  如果你想在正文前先说一句"存档完成""现在输出正文"——不要说，直接从 📰 开始。
- 读文件、写文件用工具完成，过程中**一个字都不要说**。"先读取""让我检查""现在开始翻译""重新编号"
  这类话会替代或污染正文。
- 脚本已经定好 50/50 配额、去重和顺序；不要自行判断、合并或删减，直接逐条给结果。
- **记忆 / USER.md 里的「长内容拆分多条」偏好对这个推送不适用**：定时任务只投递最后一段文字，拆分会丢掉前半部分，
  留下的（1/2）（2/2）标记还会把编号列表切断。整份正文一次输出，不拆分，不写分页标记，不写"以下是第一条/第二条消息"。
- 条目之间不能有任何其他行（空行除外）：编号从 1 连续到 N，中间不插标题、说明、分隔线。

## 你只做两件事：翻译、排版

候选清单已经由脚本完成了跨来源合并、跨天去重、噪音过滤和按重要程度排序。
**不要**再筛选、去重、排序，**不要**联网，**不要**读其他文件（尤其不要读 daily-ai-news-summary.md）。

## 执行顺序（严格按此顺序，前两步静默）

1. 用读文件工具读取 `/mnt/data/openclaw-kb/openclawdata/daily-ai-news-curated.md`。
   - 第 2 行是「生成时间」。如果距现在超过 30 小时、文件不存在、或条目为 0：跳到第 3 步，正文只写一行
     `⚠️ Daily AI News 今日无可用数据（原因：xxx）`，不要编造内容。
2. 用写文件工具**覆盖**写入 `/mnt/data/openclaw-kb/openclawdata/daily-push-history.md`（08:20 的健康检查靠它判断今天是否推送成功）。
   内容是候选文件里全部条目的**原文标题**（不翻译、不改），格式：
   ```
   # Daily Push History — YYYY-MM-DD
   ## 今日已推送标题
   - 原文标题 1
   - 原文标题 2
   ```
   日期用今天的北京日期。定时任务里无人可确认，这个固定文件直接写，不走确认流程，写完不要汇报。
3. 输出推送正文（见下）。这是你回复中唯一的文字：任何梳理、比对、编号的过程文字都不能出现在里面，输出后立即结束。

## 推送正文格式

第一行固定：`📰 Daily AI News · YYYY-MM-DD（国内 X 条｜国外 Y 条）`。日期和 X/Y 直接取候选文件标题与“强制配额”行，然后直接列条目，每条严格两行：

```
N. 【国内｜中文标题】或【国外｜中文标题】
   一句中文摘要（不超过 45 字）｜来源：A、B（共 N 家）
```

- 按候选顺序一一对应地输出全部条目，候选写“国内源”就标【国内｜…】，“国外源”就标【国外｜…】；不得改地区、重排、合并或删除。全部译成中文；语言为 zh 的条目直接润色标题，不改动事实。
- 产品名、模型名、公司名保留原文不翻译：GPT-6 Astra、Claude、Gemini 3.8 Flash、Hugging Face、NVIDIA、DeepSeek、Qwen 等。数字、金额、版本号照抄。
- 摘要只能改写候选里的「摘要」和「同事件报道」两行，不得加入候选里没有的信息，不加评论、不加表情。
- 全部条目放在同一段回复里，不拆分。
- 不带链接，不用 @all 或 @所有人，不用卡片，不用 Markdown 的 # 标题、表格、粗体。
- 正文之后**不要有任何文字**："任务完成""以上""推送已送达""存档完成"都会被当作正文发出去。
- 输出前自检三件事：正文里没有（1/2）（2/2）之类的标记；编号从 1 到 N 连续且中间没有别的行；第一个字符是 📰（补推是 ⚠️）。

## 示例

候选：

```
## 3. NVIDIA to Acquire Hugging Face
- 语言：en ｜ 来源：NVIDIA 博客、Ars Technica、New York Times — Technology（3 个来源） ｜ 热度：11.0
- 摘要：NVIDIA announced it will acquire Hugging Face for $12.9B and committed to keeping the platform open ...
```

正文中对应的两行：

```
3. 【NVIDIA 宣布 129 亿美元收购 Hugging Face】
   承诺交易后保持平台开放｜来源：NVIDIA 博客、Ars Technica、纽约时报（共 3 家）
```
